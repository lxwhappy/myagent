MyAgent

基于 Pi Agent 的智能 AI 助手 + Web 端

什么是 MyAgent？

MyAgent 是一个基于 Pi Agent 框架构建的智能 AI 助手系统
拥有现代化的 Web 界面，支持多模型切换、Agent 管理和技能扩展

🚀 快速启动
一条命令启动，无需复杂配置
🧠 多模型支持
OpenAI、Anthropic、Ollama、Google
🎭 Agent 管理
创建自定义角色，切换不同 Agent
🔧 可扩展
自定义工具、Skills 扩展

快速开始

1
克隆项目并安装依赖
# 安装依赖 pnpm install
2
配置 API Key
# 配置 Anthropic API Key export ANTHROPIC_API_KEY=sk-ant-your-key-here
3
启动项目
# 同时启动前端和后端 pnpm dev # 或分开启动 pnpm dev:server # → localhost:3000 pnpm dev:web # → localhost:5180
打开 http://localhost:5180 开始对话

核心功能

💬 智能对话
支持流式输出、实时响应、多轮对话
🎯 任务管理
自动创建任务清单，追踪进度
🛠️ 工具调用
文件操作、代码执行、网络请求等
📝 会话持久化
自动保存聊天记录，随时回顾
🔄 模型切换
一键切换不同的 LLM Provider
📊 状态监控
实时显示生成状态和工具执行

系统架构

浏览器
React
⇄
Node.js 后端
Fastify + WebSocket
⇄
Pi Agent SDK
AI 引擎

前端通过 WebSocket 与后端通信
后端使用 Pi Agent SDK 创建和管理 Agent Session
所有数据持久化存储在 ~/.myagent/

前后端分离，易于扩展和维护

扩展开发

轻松添加自定义工具和 Skills

// 添加自定义工具 const myTool = defineTool({ name: "my_tool", description: "工具描述...", parameters: { type: "object", properties: { ... } }, execute: async (args) => { ... }, }); createAgentSession({ customTools: [myTool] });
1
在 ~/.myagent/skills/ 创建 SKILL.md 文件
2
Agent 自动加载所有 Skills
3
通过 @mention 或自动触发使用
