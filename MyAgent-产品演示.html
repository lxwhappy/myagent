什么是 MyAgent？

MyAgent 是一个基于 Pi Agent 构建的 AI 智能对话系统，提供直观的 Web 界面，让你轻松与 AI 交互。

核心特性
  • 智能对话：流畅的 AI 交流体验
  • 多模型支持：Anthropic、OpenAI、Google 等
  • Agent 管理：创建和管理多个 AI 角色
  • 任务管理：内置 Todo 列表功能
  • 会话保存：自动保存对话历史
  • 技能扩展：丰富的技能库支持
快速开始
三步启动 MyAgent
步骤 1：安装依赖
pnpm install
步骤 2：配置 API Key
export ANTHROPIC_API_KEY=sk-ant-your-key-here
步骤 3：启动服务
pnpm dev

Agent 管理功能
创建自定义 Agent

点击「Agent 管理」按钮，可以创建新的 AI 角色。

  • 设置名称和描述
  • 配置系统指令（System Prompt）
  • 定义行为模式和风格
  • 分配到不同会话
默认 Agent

内置默认 Agent：通用的 AI 助手，适合大多数场景。

任务管理
内置 Todo 任务清单

当 AI 接收到复杂任务（3步以上），会自动创建任务清单，逐步执行。

  • 查看任务进度
  • 确认任务状态
  • 追踪执行步骤

AI 会按照清单有序推进，确保每一步都完成。

核心功能：对话控制
Steering（智能干预）

AI 正在生成时，你可以通过 Steering 功能：

  • 引导 AI 朝特定方向思考
  • 补充必要信息
  • 纠正误解方向
  • 控制生成节奏
Abort（中止生成）

随时点击中止按钮，停止 AI 生成。

已生成的内容会保留，便于后续继续对话。

数据持久化
所有数据保存在 ~/.myagent/
settings.json - 模型和 Provider 配置 agents.json - Agent 预设列表 workspaces.json - 工作空间管理 todos.json - 任务清单 cron-jobs.json - 定时任务 chat-sessions/ - 聊天会话历史 skills/ - 技能库 sessions/ - SDK 日志

首次启动自动从旧版本迁移数据，确保无缝升级。

常见问题
Q: 如何切换模型？ A: 在设置中配置环境变量，重启服务即可。 Q: 如何添加自定义技能？ A: 在 ~/.myagent/skills/ 目录添加 SKILL.md 文件。 Q: 对话历史保存在哪里？ A: ~/.myagent/chat-sessions/ 目录。 Q: 如何导出对话？ A: 使用会话列表中的导出功能。 Q: 支持多用户吗？ A: 当前版本为单用户设计。
