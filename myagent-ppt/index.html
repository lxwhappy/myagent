什么是 MyAgent?

MyAgent 是一个基于 Pi Agent 的轻量级 AI Agent + Web 端项目，提供了完整的 Agent 交互体验。

✦ WebSocket 实时通信
✦ React + Zustand 前端
✦ Fastify + TypeScript 后端
✦ 支持多种 LLM 提供商
✦ 可扩展的工具系统
myagent/
架构层次

浏览器 (React)
    ↓ WebSocket
Node.js 后端 (Fastify)
    ↓ Pi SDK
Pi Agent (AI 核心)
    ↓ LLM API
OpenAI / Anthropic / Ollama...

quick-start.sh

快速开始 · 三步启动

Terminal
# 1. 安装依赖
$ pnpm install

# 2. 配置 API Key（以 Anthropic 为例）
$ export ANTHROPIC_API_KEY=sk-ant-your-key-here

# 3. 启动（server + web 并行）
$ pnpm dev

# 或分开启动
$ pnpm dev:server   # → localhost:3000
$ pnpm dev:web      # → localhost:5180

# 打开 http://localhost:5180 开始对话
pnpm install 配置 API Key pnpm dev

architecture.md

架构说明 · 数据流

system-flow.txt
浏览器 (React)  ←WebSocket→  Node.js 后端 (Fastify)  ←SDK→  Pi Agent
                                  │
                          createAgentSession()
                          ├─ prompt()        → 发送消息
                          ├─ steer()         → 生成中追加
                          ├─ abort()         → 中止
                          ├─ setModel()      → 切换模型
                          └─ compact()       → 压缩上下文

WebSocket Gateway  →  路由前端指令
Session Manager    →  Agent Session 生命周期管理
Event Bridge       →  Agent 事件 → WS 消息桥接

二次开发 · 扩展指南

添加自定义工具

在 session-manager.ts 中定义工具，使用 defineTool API

切换 LLM

支持 OpenAI / Anthropic / Google / Ollama，通过环境变量配置

添加 Skills

在 ~/.pi/agent/skills 放入 SKILL.md 文件即可
